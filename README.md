# DDNet ForeEdit - DDNet 字体管理 & 修改工具

## 功能

- **字体管理** — 添加、删除字体，支持多选，自动保护内置字体
- **字体预览** — 实时预览字体效果
- **字体包** — 导入/导出字体包, 便于分享
- **通用解析** — 拖入 DDNet 快捷方式/exe/Steam 客户端 快捷方式自动查找字体目录
- **字体属性解析** — 显示字体支持语言, 字宽, 字重, 家族名称等信息

## 系统要求

- 最低Windows 7, 最佳体验为 Windows 10 / 11
- 支持 x86, x64 双架构
